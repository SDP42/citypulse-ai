# Notices and data attribution

CityPulse's **source code** is MIT-licensed (see [LICENSE](LICENSE)). The **data** it can use has its own licences, which the code does not change. Raw downloads are never committed; `scripts/` fetch/derive them locally and `data/raw/MANIFEST.json` records URL, licence and sha256 for each file.

| Data | Licence | Attribution / obligation |
|---|---|---|
| OpenStreetMap extract (Geofabrik) → roads, waterways, places | ODbL 1.0 | © OpenStreetMap contributors; extract by Geofabrik GmbH. Share-alike applies to derived *databases* you publish. |
| BMC ward boundaries (DataMeet) | CC BY-SA 2.5 India | DataMeet (Pune chapter), *Mumbai Municipal Data*. Derivatives (e.g. the ward + population layer) must carry CC BY-SA. |
| Census 2011 ward population (ORGI via OpenCity.in) | Public Domain (per OpenCity listing) | Credit: Office of the Registrar General & Census Commissioner, India, via OpenCity.in. |
| Open-Meteo historical weather | CC BY 4.0 | "Weather data by Open-Meteo.com" (https://open-meteo.com/) wherever shown. Free tier is non-commercial. |
| Synthetic fixtures (`data/fixtures/`) | MIT (generated by this project) | Fictional — says nothing about any real place. |

Sources evaluated and **not** used because no open licence was found: MCGM disaster management plan PDF, IMD public API, Praja Foundation reports. See [docs/DATA_POLICY.md](docs/DATA_POLICY.md).

The engineering blueprint in `docs/blueprint/` is the project author's planning document.
